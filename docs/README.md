# PetPal v0.0.0（未安装源码）

面向 Windows 10 及以上的 Python 桌面宠物与密码隐私屏。此目录为未安装状态，不包含虚拟环境、配置、缓存、exe 或分发压缩包。

## 使用

1. 双击根目录 `first_run.bat`，选择检测到的兼容 Python。
2. 安装器按 `[1/5]` 到 `[5/5]` 完成检测、虚拟环境创建、四源测速、依赖安装、本地编译及校验。
3. 安装后双击 `PetPal.exe`，右键通知区 PetPal 图标打开设置。Windows 可能将新图标放入右下角“隐藏的图标”区域。
4. 再次双击 `PetPal.exe` 会打开已有实例的设置；隐私屏开启时转为解锁入口。
5. 首次开启隐私屏先自定义密码，此后开启和关闭都需要验证。

要求官方 64 位 CPython 3.10–3.14 标准版本，以及 Windows 自带 .NET Framework 4.x 编译器。无兼容 Python 时打开 Python 官方下载页。安装只使用本目录 `.venv`，不修改系统 PATH 或系统 pip 配置。清华、阿里、腾讯、官方四源先测速，按测得顺序安装，失败切换下一源。

## 功能

- 桌宠：小猫、小狗、小牛、小兔四种；自主走动、进食、玩球、睡觉；支持拖动、尺寸和换装。
- 隐私屏：纯色或 `photos/` 内的图片，多显示器覆盖；导入图片复制到本地图片库。
- 设置：桌面宠物、隐私屏两个页面，圆角窗口，深色、浅色、薄荷、海洋主题。
- 密码：无默认密码，保存随机盐与 PBKDF2-SHA256 哈希；修改密码需验证旧密码。

隐私屏为普通桌面遮罩，不能代替 Windows 系统锁屏。

## 托盘处理

Windows 下使用原生通知区接口并检查注册结果，消息循环启动后才注册。每三秒检查并重试，收到资源管理器重建通知后恢复图标。注册连续失败时自动打开设置并显示提示，日志写入 `cache/logs/petpal.log`，避免只剩后台进程。正常启动强制使用 Windows Qt 平台，防止继承离屏测试设置。

安装校验记录实际 `tray_registered`，不会将“系统托盘可用”当成“图标已注册”。托盘注册失败时不写入安装成功标记。设置窗口也提供“退出程序”，退出仍遵守密码验证规则。

如果安装目录带有 Windows 低完整性标记，新 exe 会继承该标记，运行时无法向普通桌面的通知区注册图标。安装器必须从资源管理器直接双击 `first_run.bat` 启动，在已具备普通用户权限的安装进程中，以相同内容新建中完整性文件，再替换本地生成的启动器、卸载器和虚拟环境解释器。已正常的文件直接保留；无需执行可能被拒绝的 `icacls /setintegritylevel`。不修改目录标签、DACL、系统权限或环境变量，也不会请求管理员权限或自行提升进程权限。受限会话下明确停止并说明原因。

校验模式的启动器等待校验进程结束（最长 20 秒），再读取实际退出码；普通启动仍只做短暂启动检查。修复安装复用兼容的未完成虚拟环境。安装输出及错误堆栈写入 `cache/logs/install.log`。

重复运行 `first_run.bat` 时，安装器先通过本目录的本地通信通道请求 PetPal 正常退出，确认进程结束后才修复环境。隐私屏开启、正在输入密码或启用了密码保护退出时，会暂停安装并保留密码验证要求。旧版实例不支持该请求时，请在设置窗口底部点击“退出程序”；右上角 × 仅关闭设置窗口。安装器不会强制结束其他目录的 PetPal 或 Python 进程。

## 目录

未安装时根目录只有 `first_run.bat` 和 `main.py` 两个文件。

| 目录 | 用途 |
| --- | --- |
| `core/` | 应用调度、配置、密码 |
| `widgets/` | 桌宠、托盘、隐私屏、设置及主题 |
| `assets/` | 软件图标、四种宠物动画 |
| `photos/` | 隐私屏图片 |
| `tools/` | 安装、依赖、启动器和卸载器源码、本地构建与校验 |
| `tests/` | 安装器使用的功能回归检查 |
| `docs/` | 使用说明 |

运行 `first_run.bat` 后才生成 `.venv/`、`cache/`、`PetPal.exe` 和 `uninstall.exe`；使用软件后生成 `config/`。启动链为 `PetPal.exe → .venv/Scripts/PetPal.exe → main.py`，启动项小于 1 MB，不是单文件打包，不显示控制台。

双击安装后生成的 `uninstall.exe` 可移除本目录环境、缓存、配置和两个 exe，保留源码及图片。复制未安装目录到其他电脑后运行 `first_run.bat` 即可；已安装目录移动位置后请重新安装。

## 验证

安装器自动运行 `tests/test_petpal.py` 的 14 项功能检查，以及 `tests/test_setup.py` 的 8 项安装回归。检查包括修复安装的运行中实例退出与密码保护、实际替换低完整性文件并校验内容、替换失败保留原文件、实际编译 GUI 启动器、等待超过 2 秒的慢校验进程及退出码传递。原生检查在低完整性自动化会话中明确跳过；普通桌面安装时执行。
